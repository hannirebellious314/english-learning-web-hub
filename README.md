1. Open your "Downloads" folder.
2. Find the file named "english-learning-web-hub-main.zip".
3. Right-click this file and choose "Extract All".
4. Select a location on your computer to save the folder.
5. Click "Extract".
6. Open the newly extracted folder.
7. Look for the file named "index.html".
8. Double-click "index.html" to open the learning dashboard in your web browser.

## 🛠 Using the tools

The home screen displays a menu of available learning activities. Use your mouse to click on the modules you want to practice. 

* **Vocabulary Builder:** Click this link to see word lists and definitions.
* **Grammar Check:** Use this tool to enter sentences and see suggestions.
* **Reading Practice:** Access short stories and articles designed for your level.
* **Daily Quiz:** Test your knowledge with new sets of questions each day.

Your progress saves automatically within your browser cache. If you clear your browser history or cache, your progress might reset.

## 📈 Improving your English

Consistency helps most when you learn a language. Spend fifteen minutes every day with the hub to see results. Focus on the vocabulary builder before you move to grammar exercises. Use the reading tools to learn how words fit into whole sentences. 

## 🔧 Troubleshooting

If the tools do not load:

1. Close your browser and open it again.
2. Ensure you opened the file named "index.html" inside the folder.
3. Check your internet connection. Some features require a connection to reach remote resources.
4. Disable browser extensions that block scripts, as these can stop the tools from working.

If a page looks empty or broken, refresh your browser tab. Use the "F5" key on your keyboard to force a refresh.

## 📁 File structure

The folder contains several subfolders that help the application run:

* **css:** This folder stores the design files for the interface.
* **js:** This folder stores the logic that makes the tools run.
* **assets:** This folder stores images and supporting icons.
* **index.html:** This is the main starting point for the software.

Do not move these files to different folders. The application relies on this structure to find the images and logic it needs to work.
